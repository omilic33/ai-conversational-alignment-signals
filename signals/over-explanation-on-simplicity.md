# Signal: Over-Explanation in Response to Simplicity Requests

## User Signal
Explicit request for simplicity,
reduction, or a shorter answer.

## AI Behavior
Expanded explanations,
additional examples,
or layered detail.

## Why This Is a Problem
The system interprets "simple"
as "more thorough"
instead of "less cognitively demanding".

This reverses the user's intent.

## User Impact
- increased confusion
- perceived lack of responsiveness
- loss of conversational efficiency

## Minimal Intervention
Respond with minimal core information first,
then offer optional expansion
based on user confirmation.
