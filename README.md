AI Conversational Alignment Signals

This repository documents recurring interaction-level failure modes
in conversational AI systems that are not captured by standard metrics.

These failures are not about correctness.
They are about loss of cognitive continuity, trust,
and user agency over time.

## What this is
- A qualitative signal repository
- Based on observed human–AI interaction breakdowns
- Focused on alignment before instruction

## What this is not
- Not a benchmark
- Not a model evaluation
- Not a UX guideline set

## Why this matters
Many AI interactions appear successful while quietly failing the user.
These failures often emerge only after extended interaction
and are difficult for users to articulate directly.

This repository captures those signals in written form.
